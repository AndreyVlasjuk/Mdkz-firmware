# Прошивки пульта МДКЗ

Лише готові прошивки для оновлення через інтернет. Екран пульта завантажує
`manifest.json` з цього репозиторію і за ним — потрібні `.bin`.

Код — у приватному репозиторії `AndreyVlasjuk/Mdkz`; файли сюди викладає
`tools/publish_firmware.sh` або збірка GitHub Actions за тегом `v*`.
Вручну тут нічого не змінюйте.
