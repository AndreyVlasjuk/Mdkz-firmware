# Тестер шини CAN МДКЗ

Прошивка для ESP32-C3 SuperMini або ESP32-S3 SuperMini з модулем SN65HVD230
(GPIO4 → CTX, GPIO5 → CRX). Прошивати з адреси 0x0. Опис і підключення —
docs/can-tester.md у репозиторії проєкту.

- `tester-can-esp32c3-supermini-0x0.bin` — ESP32-C3 SuperMini
- `tester-can-esp32s3-supermini-0x0.bin` — ESP32-S3 SuperMini
